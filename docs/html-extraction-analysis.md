## 3. Article Extraction

### 3.1 Article Structure

Each article follows this consistent pattern:

```html
<article id="art_1">
  <a name="a1"></a>
  <h6 class="heading" role="heading">
    <span class="display-icon"></span>
    <span class="external-link-icon"></span>
    <a href="#art_1"><b>Art. 1</b></a>
    <sup><a href="#fn-...">6</a></sup>
  </h6>
  <div class="collapseable">
    <p>Article content...</p>
    <dl>
      <dt>1.</dt>
      <dd>Item one</dd>
      <dt>2.</dt>
      <dd>Item two</dd>
    </dl>
    <div class="footnotes">
      <p id="fn-...">Footnote content</p>
    </div>
  </div>
</article>
```

### 3.2 Extraction Complexity: **EASY** ✅

**Key findings:**
- Article IDs follow pattern: `art_1`, `art_2`, etc.
- Article numbers in `h6.heading` element
- Content in `div.collapseable`
- Numbered lists use `<dl>`, `<dt>`, `<dd>` tags
- Footnotes clearly marked with `div.footnotes`

### 3.3 Sample Extraction Code

```python
def extract_articles(html_content):
    soup = BeautifulSoup(html_content, 'html.parser')
    articles = []

    for article in soup.find_all('article'):
        art_data = {
            'id': article.get('id'),
            'number': article.find('h6', class_='heading').get_text(strip=True),
            'content': article.find('div', class_='collapseable'),
            'paragraphs': [],
            'items': []
        }

        # Extract paragraphs
        for p in art_data['content'].find_all('p'):
            art_data['paragraphs'].append(p.get_text(strip=True))

        # Extract numbered items
        for dl in art_data['content'].find_all('dl'):
            for dt, dd in zip(dl.find_all('dt'), dl.find_all('dd')):
                art_data['items'].append({
                    'number': dt.get_text(strip=True),
                    'text': dd.get_text(strip=True)
                })

        articles.append(art_data)

    return articles
```

### 4.2 Extraction Complexity: **EASY** ✅

**Key findings:**
- All taxonomy elements have unique, consistent identifiers
- Metadata concentrated in `div#preface`
- SR number format consistent: `N.NNN.NNN.N`
- Cross-references use standard fedlex URLs

### 4.3 Sample Extraction Code

```python
def extract_taxonomy(html_content):
    soup = BeautifulSoup(html_content, 'html.parser')
    taxonomy = {}

    # SR Number
    sr_elem = soup.find('p', class_='srnummer')
    if sr_elem:
        taxonomy['sr_number'] = sr_elem.get_text(strip=True)

    # Title
    title_elem = soup.find('h1', class_='erlasstitel')
    if title_elem:
        taxonomy['title'] = title_elem.get_text(strip=True)

    # Extract dates from preface
    preface = soup.find('div', id='preface')
    if preface:
        for p in preface.find_all('p'):
            text = p.get_text(strip=True)
            if 'Abgeschlossen' in text or 'Conclu' in text:
                taxonomy['conclusion_date'] = extract_date(text)
            elif 'Kraft' in text or 'vigueur' in text:
                taxonomy['entry_force_date'] = extract_date(text)
            elif 'Stand' in text or 'Etat' in text:
                taxonomy['status_date'] = extract_date(text)

    # Cross-references
    taxonomy['references'] = []
    for link in soup.find_all('a', href=True):
        if 'fedlex.data.admin.ch' in link['href']:
            taxonomy['references'].append({
                'url': link['href'],
                'text': link.get_text(strip=True)
            })

    return taxonomy
```

### 6.1 Pagination Handling

**Challenge**: Some documents split across multiple files
- Pattern: `file.html`, `file-1.html`, `file-2.html`

**Solution**: Already implemented in `HTMLPaginationHandler` class
```python
def group_paginated_files(html_files):
    groups = defaultdict(list)
    for file_path in html_files:
        base_name = get_base_name(file_path)
        groups[base_name].append(file_path)
    return groups
```

### 6.2 Missing Articles (30% of documents)

**Challenge**: Not all documents contain article tags

**Solution**: Document type detection
```python
def detect_document_type(soup):
    if soup.find_all('article'):
        return 'law_with_articles'
    elif soup.find('div', class_='decree'):
        return 'decree'
    else:
        return 'other'
```
